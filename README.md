# 🎓 Portal Website Kelas XI A1 (IPS) - SMA Negeri 1 Pasir Sakti

Website resmi **Kelas XI A1 (Peminatan IPS)** SMA Negeri 1 Pasir Sakti, Lampung Timur Tahun Ajaran 2026/2027. Didesain dengan estetika **Modern Bento Grid & Glassmorphism**, kaya fitur interaktif, responsif untuk HP & Laptop, serta mendukung tema Gelap dan Terang (Dark/Light Mode).

> **Catatan Privasi Siswa**: Sesuai arahan, seluruh foto siswa menggunakan **Logo Profil Avatar Vektor Modern** (desain gradien dinamis & inisial nama) tanpa menggunakan foto wajah asli orang, demi menjaga privasi dan keamanan data siswa.

## 🚀 Cara Menjalankan Website

1. Buka folder `d:\coding\web-kelas\`.
2. Klik ganda (**double click**) file **`index.html`**.
3. Website akan langsung terbuka di browser favoritmu (Chrome, Edge, Firefox) secara instan tanpa perlu instalasi `npm` atau server!
